
# Paperback Themes Collection

A collection of custom themes for the [Paperback](https://paperback.moe/) iOS app, available for both the 0.9 beta and 0.8. Featuring tailored versions for each color option.

> **Paperback 0.9 (beta):** 0.9 uses a different theme format, so its themes live in [`Paperback_0.9/`](Paperback_0.9), which mirrors the folder layout below. The 0.8 themes in the other folders will not work in 0.9, and the 0.9 themes will not work in 0.8.

## Repo Structure

The themes are organized by color or color theme. Inside each main folder, you will find variants optimized for your viewing preference:

-   **`[Color-or-Theme-Name]/`**  — The main folder containing the regular theme (e.g.,  `Winter_Solstice`,  `Red`,  `Light_Blue`).
    
    -   **`Black_Dark_Mode/`**  — BDM in the file name. Contains the version with the dark mode background set to pitch-black (ideal for OLED screens).
        
    -   **`Black_All_Modes/`**  — BAM in the file name. Contains the version with the background set to pitch-black across both light and dark mode (ideal for OLED screens).
        

## Editor Color Scheme Themes

Ports of popular editor color schemes, each with Standard, BDM and BAM variants. Where a scheme has an official light companion, it is used for light mode.

| Folder | Themes | Light mode |
|---|---|---|
| `Catppuccin/` | Frappé, Macchiato, Mocha | Latte |
| `Gruvbox/` | Gruvbox Dark | Gruvbox Light |
| `Kanagawa/` | Wave, Dragon | Lotus |
| `Monokai/` | Monokai | Monokai Pro Light |
| `Nord/` | Nord | Nord Snow Storm |
| `One_Dark/` | One Dark | One Light |

These are generated by [`tools/generate_themes.py`](tools/generate_themes.py). Edit the palettes there and run `python3 tools/generate_themes.py` from the repo root to regenerate them.

## Paperback 0.9 Themes

Every 0.8 theme is converted to the 0.9 format by [`tools/convert_to_v09.py`](tools/convert_to_v09.py), which writes the result to the same path under `Paperback_0.9/`. After adding or changing a 0.8 theme, run it from the repo root to regenerate the 0.9 versions:

```sh
python3 tools/generate_themes.py   # only if you changed the editor color scheme palettes
python3 tools/convert_to_v09.py
```

The 0.9 status colors (success, warning, error and alert) use Paperback's defaults, since 0.8 themes have no equivalent.

## How to Apply Themes in Paperback

Follow these steps to download and apply your chosen theme.

Step 1 -
**Download the Theme File:**

If on iOS device you can find themes from url below:

[`https://abishekaditya.github.io/themes-paperback`](https://abishekaditya.github.io/themes-paperback)

Pick **Paperback 0.9 (beta)** or **Paperback 0.8** at the top of the page to match your app, then download the theme you want directly to your device's  **Files** app.

> ⚠️  **Paperback 0.9 only imports a file named `themeColors.pbcolors`.** The site saves 0.9 downloads with that name. If Files adds a number (for example `themeColors 2.pbcolors`), delete the older copy or rename the new one back to `themeColors.pbcolors`. If you download from GitHub directly, rename the file yourself.

Step 2 -
**Prepare the App:**

Open the  **Paperback**  app so it is running in the background.

Step 3 -
**Open via Files App:**

Open your device's  **Files**  app and locate the downloaded theme file. Either tap it to open, or  **long-press**  the file, select  **Share**, and choose  **Paperback**  from the app list.

Step 4 -
**Force Restart to Apply:**

Once Paperback automatically pulls into the foreground,  **fully close the app**  from your device's app switcher (swipe it away), then  **reopen it**. Your new theme will now be applied.

> 💡  **Tip:**  If you are using a  **Black Dark Mode**  variant, ensure your system or app setting is forced to Dark Mode to experience the OLED pitch-black profile.
